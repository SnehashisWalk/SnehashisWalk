### 🤖 What I work on

- **Robot data pipelines:** processing that turns field sensor data into maps, 3D reconstructions and reports
- **Orchestration at scale:** Apache Airflow on AWS and Kubernetes, for CPU and GPU workloads
- **Cloud platform:** AWS infrastructure as code (EKS, S3, IAM, SSO) with CDK, Helm and Argo CD
- **Cloud and edge:** one set of pipelines, running in AWS and on-site
- **Reliability:** monitoring, alerting and failure analysis, so every failed run has a clear reason
